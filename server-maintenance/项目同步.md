# 通过大肥鱼维护项目

电脑和服务器以 SSH 同步私有的 `project` 分支。服务器工作树是 `/home/ubuntu/qq-owner-ops/workspace/bigfish`。电脑使用项目原目录，私用 Git 索引在 `.private/project-sync/local.git`，现有 GitHub 仓库仍可独立审查和发布代码。

## 在 QQ 交代工作

用本人 QQ 私聊大肥鱼，例如「进入root模式，帮我修改养殖基地仓库的生图功能，支持……，跑测试并提交」。项目任务在服务原有权限内运行。完成后可以说「查询任务结果」，核对提交短号。线上服务的部署可在委托中另行说明。

## 电脑取回完成的提交

在项目根目录运行：

```powershell
./server-maintenance/project-sync.ps1
```

可以先用 `-Mode Status` 查看本机改动、两边各自独有的提交数和服务器待提交文件。服务器端需要先提交改动，拉取只处理提交。需要时用 PowerShell 7 执行脚本。

## 电脑发回自己的改动

```powershell
./server-maintenance/project-sync.ps1 -Mode Save -Path 'server-maintenance/images/image_commands.py' -Message '调整改图识别'
./server-maintenance/project-sync.ps1 -Mode Push
```

两边准备编辑同一文件时，先拉取，再修改、验证并提交。遇到重叠修改或分叉，脚本会停下来保留两边版本，可以让 Codex 对比后合并。运行令牌、聊天数据、二维码和服务器实际账号配置继续存放在原有私有位置。GitHub 发布前仍需单独检查源码中的真实账号等标识。
