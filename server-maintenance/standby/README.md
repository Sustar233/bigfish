- QQ连续两次健康检查不可用时，大肥鱼在自己的QQ接待本人；发给离线小c的私聊无法接收或代收。
- 小c QQ仍在线，但Codex返回额度、认证、网络、超时或生成错误时，在小c原号使用“大肥鱼临时值班”的短话术。

- 临时话术由程序直接选择，不调用DeepSeek或聊天模型，不发送语音、表情附件。QQ语音转写可沿用已有原生能力；不是让离线账号仍然收消息。
- 原有后台新闻、监控、定时器和已存在任务配置保持不变。其他好友及其他账号不进入本人的临时模式。

## 状态与恢复

`standby.py` 部署在 `/home/ubuntu/qq-codex/bridge/`；状态数据库为同目录 `.private/standby.sqlite3`，权限600，只保存健康标记和探针时间，不保存消息正文、凭据或任务。

QQ状态复用既有两分钟巡检。确认在线后清除QQ离线标记。模型不可用另记状态，QQ恢复不等于模型已恢复；既有巡检在QQ在线且模型异常时最多每五分钟启动一个独立恢复探针。探针时限60秒，仅请求 `READY`，关闭shell、图片工具、apps、远端插件、hooks、搜索及多代理；用量归 `system_verification`。只有正常完成且明确返回 `READY` 才恢复常态，失败不反复发送通知。没有新增定时器，也没有切换付费API。

入口覆盖小c工作队列、Harness插件白名单之后且工具之前、三人群本人消息去重之后、好友接入中的本人支路，以及共享图片任务提交入口。已有功能代码保留，临时模式结束后按原配置恢复。图片任务首次返回已知模型不可用错误时也能进入接待模式。
