## 实际行为

- 语音输入：只接收白名单好友语音，通过 NapCat `fetch_ptt_text(message_id)` 调用 QQ 原生转写。最多两次尝试，失败明确提示，不调用模型猜内容。
- 转写成功：按原始来信时间保存文字和语音转写来源，接入已有聊天、检索与待确认记忆流程。不自动批准新记忆。
- 默认回复模式 `auto`：语音来信收到文字和语音回复，文字来信通常只回文字。自然语言“用语音回我”等也可触发。
- TTS：隔离虚拟环境里的 `edge-tts`，使用 Microsoft Edge 在线音色；只提交需要朗读的回复文字，不提交历史、记忆或服务器配置。没有配置新的付费 API。
- 默认普通话男声 `zh-CN-YunxiNeural`，可切换女声 `zh-CN-XiaoxiaoNeural`。
- 超过240字符或含长代码的回复保留完整文字，语音作简短提示。音频使用临时文件，发送后清理。
- 表情：8张原创鱼塘图片，由本轮模型在同一条结构化回复中选择固定标签；没有增加独立的选图模型请求。自动表情至少间隔5分钟，明确索取不受该间隔限制。
- 图片路径、音色与收件人均由程序控制，模型不能指定路径、网址或外部收件人。
- 已成功发送的文字不会因后续语音/图片失败而被重发。语音/图片发送结果不明确时，不自动重发。

## QQ 使用方法

直接发语音，或发送“用语音回我”“来张表情包”。

```
/语音 自动
/语音 开启
/语音 关闭
/语音 男声
/语音 女声
/语音 测试
/表情
/表情 得意
/表情 递报
/表情 开启
/表情 关闭
```

`/语音 关闭` 关闭日常语音回复，仍然接收和转写用户语音；明确要求语音时仍可按需发送。

## 文件

- `qq_media.py`：转写、设置、固定目标媒体发送。
- `tts_worker.py`：语音合成子进程。
- `stickers/`：图片与固定标签清单。
- `.private/media-settings.json`：语音模式、音色、表情开关和间隔。
- `.private/media-venv/`：隔离依赖；精确版本见 `.private/media-requirements.lock`。
- `.private/media-smoke-2026-11-16.json`：真实发送消息ID和QQ原生转写验证结果，不含语音正文。
