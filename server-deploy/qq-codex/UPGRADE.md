# QQ 角色时间、会话和搜索升级

2026-11-16。基于现有 Codex CLI / ChatGPT 登录，不引入其他模型 API。

- 每轮注入北京时间、消息时间、上次发言时间、间隔和会话状态。
- 空闲 2–6 小时缩短近期上下文；超过 6 小时默认新会话。午夜不机械清空。档案始终保留。
- 旧滚动历史若缺原始时间，不推断时间、不直接当成本轮上下文；旧档案保留。
- 仅当用户提到过去的话题时自动召回原文；召回附日期，敏感凭据不回填。
- 长期偏好保留；不相关的事件不默认填入每轮提示词。候选记忆仍需确认。
- 私聊与群聊分别检索；群聊不自动读取双方私聊档案及确认记忆。
- 公开查询使用独立检索调用：只传本轮人类查询，不传角色设定、历史或记忆；邮箱与长编号先脱敏。
- 普通明确查询使用 cached；时效查询使用 live。必须观察到真实 web_search 工具事件并取得来源，才确认搜索成功。
- 回复合成调用关闭搜索；服务器命令、文件工具、应用插件、多代理和 hooks 继续关闭。
- 非公开地址、带凭据地址和疑似密钥不送入检索；不增加服务器上的任意 URL 抓取器。
- 群聊保留本人触发、固定三人群校验、每轮最多两条及原有限额。
- 此版未增加提醒、主动消息、附件处理或服务器管理能力。

验证：41 项 unittest 通过；真实时间及隔天聊天、cached 搜索、live 搜索探针通过。
探针仅调用模型，不向 QQ 发送测试消息。

部署前在服务器私密目录备份原代码，并使用 SQLite backup 保存在线数据库快照。
只重启 qq-chat.service 和 qq-group.service，不重启 QQ 账号容器。
