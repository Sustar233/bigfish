## 区分档案、近期上下文与长期记忆

**档案**保存已经接收到的聊天原文；没有按轮数滚动删除。Codex 本次迁入旧缓存 28 条，Harness 迁入已有可见记录 20 条；此前已被旧缓存裁剪、且无其他副本的 Codex 消息无法补回。Harness 每两分钟增量采集，进程停止或采集失败时可能延后；不归档模型内部推理、工具日志和系统提示词。

Codex 归档白名单私聊中的文字；目前不识别图片、语音等内容。Harness 保留可见文本与媒体描述／引用元数据，没有另行下载媒体二进制文件，原始 QQ 媒体链接可能失效。Harness 的 engine_recorded 状态代表引擎记录，不等同 QQ 已送达；Codex 则标明 sent、生成但未确认送达等状态。

**近期上下文**是 Codex 提交模型的最近 20 轮，另有长度限制。/清空 只重置当前话题，不删除档案或记忆。Codex 还会按当前问题关键词，从自己的档案召回少量相关旧消息；这是轻量关键词检索，不能保证每次都找到，也不能推断未保存的事实。

**长期记忆**保存明确的偏好、项目、约定。/记住 直接保存用户输入；Codex 模型提出的候选先进入待确认列表，用户确认后才参与长期记忆注入。不保存模型推测为既定事实；检测到常见密钥或密码格式时拒绝加入记忆。两个账号的数据库与记忆文件独立，不自动互通。

注意：/忘记 移除该长期记忆条目，原始档案与旧备份仍保留；历史检索仍可能找到原文。它不是彻底删除个人资料的指令，需要彻底删除时应单独处理原档案、导出文件和备份。

## 给 Codex 小号发送的命令

| 命令 | 用途 |
|---|---|
| `/帮助` | 查看说明 |
| `/清空` 或 `/new` | 开始新话题，保留档案与记忆 |
| `/记住 我喜欢简洁的中文回答` | 明确保存长期偏好 |
| `/查看记忆` | 列出有效记忆 |
| `/待确认记忆` | 查看模型建议 |
| `/确认记忆 M3` | 激活指定建议 |
| `/忘记 M3` | 移除指定长期记忆 |
| `/查记录 咖啡店` | 在自己的原始档案中查关键词 |
| `/导出 md` | 发送 Markdown 档案附件 |
| `/导出 html 2026-11-14` | 发送某日的可浏览 HTML 档案 |
| `/导出 jsonl` | 导出机器可读记录 |
| `/状态` | 查看聊天桥状态 |

单个附件最多 8 MiB，超出时按日期导出。HTML 中消息正文会转义，不作为脚本运行。

同一入口管理 Harness 档案时，把 Harness 放在命令之后：

```text
/记住 Harness 我希望回复更简短
/查看记忆 Harness
/确认记忆 Harness M3
/忘记 Harness M3
/查记录 Harness 关键词
/导出 Harness md
```

这些命令发给 Codex 号。Harness 不额外安装重复的命令解析器；其长期记忆写入 USER_MEMORY.md，由插件在创建／恢复会话时注入，后续更新可给 Harness 号发送 /new 加载。/清空 Harness 只会提示到 Harness 开新会话，不会清掉 Codex 的话题。

## 备份与提醒

- 服务器每天 03:30 生成两个账号的 SQLite 一致性快照、确认记忆及已选人设，并加密为 .qqbak；保留最近 30 天备份。30 天轮换仅适用于备份文件，当前档案没有按日期删除。
- 加密采用 RSA-OAEP-SHA256 封装随机密钥，AES-256-GCM 加密并认证正文。服务器只保存公钥。
- 本机 Windows 任务 QQ-Encrypted-Backup-Pull 在每天 09:30 和登录时拉取加密备份；电脑关机时无法同步，登录后补拉。已实际运行成功。
- 本机还原私钥由当前 Windows 用户的 DPAPI 保护，保存在 .private-backups/restore-key.dpapi。它不能直接搬到另一个 Windows 用户／重装后的系统使用；迁移或重装前，必须先在当前账户完成解密恢复或安排可迁移密钥备份。不要只复制 .qqbak 就认为可恢复。
- 已用真实备份完成解密验证；被篡改的密文验证失败且没有写出明文。
- 每两分钟检查两个 QQ 账号；连续两次失败后向 owner@example.com 发邮件，恢复后通知。异常重复提醒间隔至少六小时。Codex 模型调用失败也会分类提醒；提醒不附聊天内容或令牌。已实际发送 SMTP 测试邮件。
- 不为故障自动重启 QQ 容器、不反复扫码重试，避免触发账号安全验证。定时采集、备份与检查不调用大模型。

本机恢复示例（在可信环境执行，输出为含私人聊天的 tar.gz）：

```powershell
pwsh -NoProfile -File .\backup-local.ps1 -Mode Pull
pwsh -NoProfile -File .\backup-local.ps1 -Mode Restore -InputFile <备份.qqbak> -OutputFile <还原.tar.gz>
```

保存导出附件、明文还原包和本机私钥时，应视为私人资料。
