# 小c和肥鱼的本人私聊定时提醒

2026-11-21 用户授权两号增加定时提醒，并明确“他们”默认指小c和肥鱼（大肥鱼）。别名已作为用户明确记忆写入两个号各自的记忆库，没有改人设身份。

## 使用

给哪个号私聊，就由哪个号向本人1000000001发送。默认北京时间，支持一次、每天、工作日、每周和固定间隔；提醒内容是到点发送的文字，不会执行文字中的命令，也不在到点时调用模型。

- “半小时后提醒我喝水”
- “明天早上八点提醒我开会”
- “每天晚上八点提醒我看书”
- “工作日9:30给我发一句早安”
- “每周五下午三点提醒我整理资料”
- “每隔30分钟提醒我起来走走”
- “查看我的提醒”或 `/提醒列表`
- “把刚才的提醒改到明天8点”
- “取消刚才的提醒”或 `/取消提醒 编号`

小c使用确定性中文时间解析，不明确或不支持的时间不能当成已设置；肥鱼使用 `server_reminder` 工具，复杂时间可先查询服务器时间。肥鱼支持任意已有编号的修改，小c支持修改最新提醒或 `/修改提醒 编号 时间`。成功确认包含下次北京时间和提醒编号。

## 架构与边界

- 独立 `qq-reminders.service`，已启用开机启动；主目录 `/home/ubuntu/qq-reminders`。
- SQLite数据库 `data/reminders.sqlite3`，私密目录及文件；Unix接口 `/run/qq-reminders/control.sock`，仅ubuntu可访问，核验调用UID、真实接入的私聊来源、本人号及对应机器人。
- QQ目标固定为1000000001，不接收用户指定的第三方收件人或群号。现有群聊程序没有接入提醒入口，肥鱼工具另校验私聊session。
- 普通提醒不使用 Codex/Harness 执行任务服务，不创建任意cron，不执行shell，不增加服务器操作权限。
- 小c入口为现有 `Bridge.command` 中插入 `reminder_client`；保留媒体、新闻、空间点赞和服务器执行入口。肥鱼在既有QQ限定owner-tools中注册 `server_reminder`，不改全局网页预设。
- 每号最多100条活动提醒；重复提醒最短1分钟。默认只管理本号提醒，不自动让两个号各发一次。

## 可靠性与发送结果

约每3秒检查到期项，实际投递还受QQ接口响应影响，不承诺精确到秒。数据库支持重启恢复、幂等创建、取消、修改；每个提醒时点有唯一投递记录。

先检查对应QQ是否在线，再持久记录发送尝试并调用接口。离线或检查失败时每分钟重查，最长补发24小时内的消息；超过24小时的一次提醒标为过期，重复提醒跳过旧时点，不集中补刷。延迟超过5分钟附原定时间。

发送成功保存QQ回执。超时、结果不确定或在发送中重启时不会盲目重发：一次提醒标为待核对，重复提醒进入下次时点并保留上次错误。无法在QQ接口不支持幂等发送的前提下同时保证绝不漏发和绝不重复，此处优先避免重复发送。

取消正在发送的消息可能来不及阻止已发出的那条，取消确认会说明这一点。
